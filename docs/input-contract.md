# 原始资料契约

所有机构、车辆、单据和设备均为本地合成，不来自新闻中的真实企业，也不声称新闻发生过这些事件。

金额minor为币种最小单位整数，CNY与USD均为分，币种之间没有默认换算。费用身份line/revision，采用明确supersedes的替代关系；跨币种替代无业务确认不能接受。红冲id唯一，target是原费用行/修订；只冲该行金额，同币种累计红冲不得超过该行可冲金额，异常红冲不影响其他行。
cargo.ticket为货票；同运次可多票同物料，运次重量按有效货票求和，不能按费用连接行数计。tickets为空表示本运次全部有效货票，否则仅所列票。basis=weight用精确吨数，pieces用件数；未知基数不当作0，也不将未知票排除后偷偷重新归一。
分摊目标是费用行扣合法红冲后的minor。对精确比例先取绝对金额的整数下界，余分按余数降序，余数相同按ticket字典序分派，再还原正负号。return表示可查的退运量，不抹掉原运次发生的运输事实；后续适用费用要以各费用声明范围为依据。

seed.json与同名Parquet保存相同的输入值，actions.json中的后续动作尚未处理。inventory.json只校验原件物理完整性，不是仓库目录或业务结论。所有后续仓表与接口均待开发，源码不规定其架构。

退运动作只增加独立可查的返程运输记录，不更改已发生的原运次重量及其原始分摊基数；原始载重有误时用cargo的replace明确更正，费用变化则由费用修订或红冲声明，不能由退运自行推断减费。
